# 色块幸存者

浏览器里直接开打的割草小游戏。自动攻击，你只管走位，边跑边升级，看能活多久。一局一两分钟。

**零依赖、零构建**：一个 `index.html` 加一批 ES module 源码，配个静态服务器就能跑，没有 npm 依赖、没有打包步骤。

## 本地跑

```bash
npm run serve      # 等价于 python3 -m http.server 8080
# 打开 http://127.0.0.1:8080
```

不能直接双击 `index.html`——用了 ES module，`file://` 协议下会被 CORS 拦掉，必须经 HTTP 服务。

## 开发命令

```bash
npm test           # 逻辑层 + 渲染层烟测 + 内容契约 + 存档回放 + 局外进度 + UI 排版（233 个）
npm run balance    # 平衡回归报告（给人看的）：武器强度、局长、兵种出场、帧率无关性、单帧耗时
npm run check      # 平衡断言（给 CI 用的）：不合格直接非 0 退出，约 105 秒
npm run check:quick # 快速档：3 个 seed + 跳过两组重型检查，约 20 秒。样本量敏感的断言降级成提醒
npm run size       # 体积检查：零构建，源码原样下发，gzip 后不许超 220KB
npm run validate   # 内容表结构校验
npm run arch       # 架构约束：确定性、依赖方向、颜色来源、fx 事件登记（约 0.1 秒）
node tools/make-og.mjs   # 重新生成分享卡片图 og.png
```

## 固定种子与录像

世界是确定性的（固定步长 + 可导出状态的随机数），所以同一个种子加同一串输入必然重演同一局。

- 看自己上一局的回放：阵亡结算里按 `R` 或点「看这局回放」，会把你刚才那局从头原样播一遍
  （连暴击、刷怪、你按的每一次冲刺都一样）。回放中 `ESC` / 点击退出，空格直接重开。
- 分享同一局：URL 加 `?seed=1234`（要完全一致再加 `?seed=1234&hero=ranger`），死亡后重开也用同一个种子。不带参数就随机。
- 录一局机器人对局，改完数值再重放，直接看行为差异（比看平均值靠谱）：

```bash
npm run record -- 7 120 run.json          # seed 7，录 120 秒，写到 run.json
npm run record -- 7 120 run.json ranger   # 指定角色
npm run replay -- run.json                # 重放并核对 { 时长, 击杀, 等级, 是否结束 }
```

`src/replay.js` 还提供 `snapshot(w)` / `restore(snap)`，把世界存成纯 JSON 再读回来（存档就靠这个）。
存档带版本号：比当前老但不太老的档（`MIGRATABLE_FROM` 起）会**按缺失字段补默认值**继续用，
太老或比当前新的才丢——这几天版本号从 8 涨到 11，每次都静默丢档，而每次加的其实只是新字段。

## 代码结构

逻辑层（可在 node 里直接跑，测试和平衡脚本都依赖这一点）：

- `src/sim.js` —— 世界状态与每帧编排：玩家移动、冲刺、子弹、经验、伤害记账（`w.log`）。
  不碰 DOM。
- `src/enemies.js` —— 兵种表、刷怪、各兵种行为（含 Boss 状态机）、波次节奏。
  **不 import sim.js**：它需要的能力（生成子弹、登记 fx、从池取对象）由 sim 通过 `ctx` 注入，
  这样两边不会循环依赖。
- `src/upgrades.js` —— 通用词条、诅咒卡、武器升级/进化、每次升级抽三张，以及交界 Boss 的战利品表。
- `src/heroes.js` —— 角色表：起手武器 + 一条属性修正。写法和词条一致（一条配置 + 一个 `apply`），
  加角色只要往 `HEROES` 里加一项，内容校验和平衡断言会自动带上它。
  第一个角色是**基准角色**，不带任何修正，所有历史平衡阈值都以它为锚点。
- `src/difficulty.js` —— 难度表（倍率 + 解锁条件）和通关奖励。第一档是基准难度，三个倍率都是 1。
- `src/elites.js` —— 精英原型表：自爆 / 护盾 / 裂变三套机制，写法和 Boss 原型一致。
- `src/bosses.js` —— Boss 原型表：招式权重、血量倍率、裂变/护卫机制、描边色。
  第一个原型是基准原型（招式权重和加原型之前完全一致），历史 Boss 平衡数据以它为锚点。
- `src/zones.js` —— 区域表：兵种权重倍率、地形覆盖、冲锋潮兵种、Boss 原型、色调。
  权重是"在 KINDS 基础权重上乘多少"而不是绝对值，这样调兵种基础强度时区域配比会跟着走。
- `src/achievements.js` —— 累计统计的累加规则 + 成就表（`progress()` 返回 `[当前, 目标]`，
  判定只读统计和存档，所以随时可以重算，不需要存"已解锁"）。
- `src/meta.js` —— 局外进度：残片结算公式、角色解锁价、永久强化表。
  全是纯函数（存取 localStorage 在 `game.js`），所以测试和平衡脚本能直接用。
  默认状态必须和"没有这套系统"时完全一致，否则平衡阈值会跟着玩家存档漂移。
- `src/weapons.js` —— 武器定义。每把武器 = 一条配置（数值表、升级文案、面板 info）+ 一个 `tick`。
  加武器只需往 `WEAPONS` / `EVO_WEAPONS` / `AWAKEN_WEAPONS` 里加一项。
  三张表分别是基础、进化（两把素材合一把）、觉醒（进化武器满级后的终态，走战利品）。
- `src/skills.js` —— 主动技能定义，和 weapons.js 同一套写法（一条配置 + 一个 use），
  能力由 sim 通过 ctx 注入。
- `src/terrain.js` —— 地图元素：岩块、泥地、宝箱。地图是无限的，所以它们围着玩家动态
  生成、走远回收；同样不 import sim.js，能力由 ctx 注入。
- `src/tuning.js` —— **所有可调数值集中在这里**（玩家属性、冲刺、经验曲线、刷怪与难度、
  波次、Boss 行为、地形、选卡次数）。改任何一个都可能动平衡，改完跑 `npm run balance` 对比。
- `src/validate.js` —— 内容表校验：desc 条数对不上 maxLevel、缺 `info()`/`tick()`、
  进化配方指向不存在的武器等，都在这里一次性报出来。
- `src/fx-events.js` —— fx 事件类型的唯一登记表。`emit()` 会校验类型，
  测试会检查每种事件都有渲染层处理。
- `src/pool.js` —— 对象池与确定性随机（随机数状态可导出/灌回，快照和回放靠它）。
- `src/replay.js` —— 世界快照（存档）与输入流回放（seed 分享、录像、数值改动前后对比）。
- `src/view.js` —— 逻辑视野尺寸常量，单独成文件避免循环 import。

渲染层：

- `src/game.js` —— 只剩装配和主循环：输入、固定步长累加器、异常兜底。
- `src/render` 相关：`src/shapes.js`（形状/描边/网格/暗角）、`src/hud.js`（HUD、暂停面板、
  选卡、死亡结算、首屏）、`src/fx.js`（粒子/跳字/闪电/震屏，消费 sim 登记的 fx 事件）、
  `src/layout.js`（UI 命中区域，绘制和点击判定共用一套坐标）。
- `src/progress.js` —— 局外进度的持久化层：最好成绩、选中的角色、残片与解锁、难度。
  只跟 localStorage 和 `meta.js` 的纯函数打交道，不碰世界也不碰画面；每个写入都吞掉异常
  （无痕模式会抛，但"存不下"不该让游戏崩）。
- `src/sandbox.js` —— 武器沙盒（工具屏）的全部状态与交互。通过一个 `host` 拿"换一个干净世界"
  和"回主菜单"两件事，其余留在 `game.js`——拆出来是因为 `game.js` 已经同时扛着
  输入 / 主循环 / 渲染编排 / 局外状态四件事。
- `src/palette.js` —— 语义化色板，其他文件零硬编码色值。
- 表现层的"动作感"全部只动渲染层（`fx.js` / `game.js` 的 render），逻辑一个字节不改：
  冲刺残影按帧采样、击杀碎片按兵种形状拆块、命中火花沿"玩家→目标"方向喷、
  时缓给敌人套冷色光环、磁吸给经验球拉尾迹；玩家内环朝移动方向偏心、移动时形状沿前进方向拉长；
  Boss 预警在地上画指示（冲撞一条带子、弹幕一圈放射线、召唤几个圈）；
  子弹按发射它的武器换形状（长条 / 菱形 / 方块）并给高速弹拖尾、敌人脚下补阴影、
  相机朝移动方向前瞻并阻尼跟随、血量低于 40% 出现呼吸红边、进入拾取范围的经验球拉尾迹；
  升级弹两层金色冲击环 + 玩家短暂发光、精英/Boss 残血套一圈暗红、
  进化与觉醒武器的弹体带光晕（Canvas 2D 没着色器，用放大的半透明同色轮廓伪造）、
  岩块压投影、泥地补一道内圈波纹；敌人出场有落地涟漪、被眩晕时头顶有标记、
  冲锋潮来袭时四条边一起亮。
  这样回放确定性和平衡断言都不受影响。
- `src/audio.js` —— 音效全部 Web Audio 现场合成，不加载音频文件。

主循环用**固定步长**（逻辑恒定 1/60，渲染用真实 dt）。之前是变步长，同一个 seed 在
30/60/144fps 下能跑出 441s / 113s / 77s 三种结果，平衡数据完全不可比。

## 这个项目的硬规则（`npm run arch` 会拦）

新来的人最容易踩、而且破坏后果都是**静默**的四条。它们不再靠注释和记忆，`tools/arch-check.mjs` 在 CI 里守着：

1. **逻辑层必须完全确定性**：`sim.js` / `enemies.js` / `weapons.js` / `skills.js` / `terrain.js` /
   `upgrades.js` / `zones.js` / `bosses.js` / `elites.js` / `meta.js` / `achievements.js` /
   `difficulty.js` / `heroes.js` / `pool.js` / `tuning.js` / `replay.js` 里不许出现
   `Math.random()` / `Date.now()` / `performance.now()`——随机数只能来自 `w.rng()`，时间只能来自 `w.t`。
   破坏它的后果是录像和存档从此不可重演，而游戏表面照常运行。
2. **逻辑层不许碰 DOM**（`document` / `window` / `localStorage` / `requestAnimationFrame`），
   也不许 import 表现层（`game.js` / `hud.js` / `fx.js` / `shapes.js` / `audio.js` / `layout.js`）。
   它必须能在 node 里裸跑——测试和平衡脚本都建立在这一点上。
3. **`enemies.js` / `weapons.js` / `skills.js` / `terrain.js` / `upgrades.js` / `zones.js` /
   `bosses.js` / `elites.js` 不许 import `sim.js`**：它们需要的能力由 sim 通过 `ctx` / `api` 注入，
   否则是循环依赖。
4. **颜色只能来自 `palette.js`**（`#fff` / `#000` / 纯白纯黑的半透明覆盖层除外），
   **新 fx 事件必须先进 `fx-events.js` 的登记表**——`emit()` 的调用点由 arch 检查，
   "登记表 ↔ 渲染层处理"由契约测试双向检查。

## 加内容的约定

- 加武器 / 技能 / 兵种 / 地形：往对应模块的表里加一项即可，不用改 `sim.js`
- 调数值：只改 `tuning.js`，然后 `npm run check`（断言）+ `npm run balance`（看具体数字）
- 新增 fx 事件：先加进 `fx-events.js` 的登记表，否则 `emit()` 会直接抛错；
  再去 `fx.js` 的 `handlers` 里加处理，否则契约测试会失败
- 写测试：用 `test/fixtures.mjs` 里的 `labWorld` / `putEnemy` / `putTerrain` / `run`，
  不要再各写一遍造实体的代码
- 改 UI 文案或坐标：`test/ui-layout.test.mjs` 会把每个界面画一遍、量出所有文字的包围盒，
  互相重叠或跑出画布都会直接失败（连按钮命中区互压也拦）

## 平衡断言在拦什么

`npm run check` 把这个项目里真实踩过的坑写成了硬规则，CI 里不通过就不许合入：

1. 内容表结构校验（`validate.js`）
2. **每一级升级都得有用**：单体台架或群体台架至少一项提升 2%。
   两个台架都要有，因为"弹道 +1""目标 +1""爆炸范围 +"这类升级在单体上完全看不出变化
3. 满级武器必须既能打到贴身（21px，敌人会压到这个距离）也能打到远处之一
4. 进化不该明显弱于素材双持
5. 一局必须会结束（5 个 seed 都要在 400 秒内），且平均长度在 40–260 秒之间
6. 所有兵种都要在 5 局里露过面（防解锁时间/权重写错）
7. 帧率无关性：30 / 60 / 144fps 走同一套累加器，结果必须一致
8. 单帧逻辑耗时 < 2ms（当前极端场面 600 怪 + 400 弹约 0.87ms）
9. 局外强化不能把难度曲线抹平（满级存档不超过新存档的 1.8 倍）
10. 每个 Boss 原型都能在 150 秒内打死，平均耗时 5–130 秒
11. 通关可达（满级强化 10 局里至少通关 1 局，通关时刻中位落在三段清场时间到 400 秒之间）+ 噩梦确实更难
12. 无尽轮次有递进（第 3 轮中位存活 ≤ 第 1 轮的 85%）且不会一进去就墙死
13. 每种精英都不会把一局砍掉一半，也不会比基准还轻松

## 玩法

- **界面分屏**：主菜单是 2 列 × 3 行的卡片网格（开始游戏 / 继续上一局 / 局外强化 /
  成就与统计 / 操作说明 / 武器沙盒），方向键在网格里走、回车确认、数字键 `1`-`6` 直达。
  局外强化、成就与统计、操作说明、武器沙盒各占一屏，`ESC` 返回。
  只有明确点菜单项才会开局，按别的键或点空白处不会误触。
- **开局前的配置屏**：点「开始游戏」不直接开局，而是进角色屏——选角色（点卡片或 `1`-`4`，
  默认停在上次用的那个）、选难度（`D`），然后按「开始（回车）」才真正开局，`ESC` 可以退回主菜单。
  以前「开始游戏」和「选择角色」是两个都能开局的入口，区别只有"用不用上次的角色"，
  而且在角色屏点一下卡片就直接开局了——和"只认明确的开局意图"那条自相矛盾。
  卡片上还显示这个角色的最长存活，选之前能看出自己哪个练得最好。
- **角色**：新兵（追踪弹，无修正）／游侠（穿透枪，移速攻速）／术士（光环，伤害拾取，走得慢）／猎手（回旋镖，暴击经验）。
  选过的角色会记住，主菜单第一项就是「用上次的角色开局」。没解锁的角色在「局外强化」屏里买。
- **局内 HUD 只留决策信息**（血/经验/冲刺、时间、区域倒计时或「Boss 战」、Boss 血条与打断进度、技能槽），
  装备、阶段、精英倒计时、最好成绩这些收进 `Tab` 详情浮层。
- **暂停分三页**（装备 / 属性 / 战况，`1–3` 或点标签换页），**结算分两页**（总览 / 详情）。
- **中断后接着打**：暂停面板按 `Q`（或点按钮）返回主界面，会自动存档；首屏按 `C` 继续上一局。
  存档只有一个档位，读出来就消掉；阵亡和重开都会清档（否则可以"死了再读档"反复刷通关）。
  读档继续的那一局不再录像，所以没有回放可看。
- **通关与难度**：走完荒野 → 沼泽 → 巢穴 → 雪原，打倒最后一个区域的交界 Boss 即**通关**
  （四段各要清场 45 秒再打一场 Boss，满级强化下的通关时刻中位约 270 秒）。
  通关弹结算面板，可以选「继续无尽」（区域继续循环、难度继续涨）或直接重开，另外给 60 残片奖励。
  首次通关解锁**噩梦**难度（敌人血 ×1.45、移速 ×1.12，残片 ×1.5）——在开局前的角色屏按 `D` 切换。
- **无尽轮次**：通关后继续打，区域循环完一整轮记一轮。敌人加成按**打通的段数**算
  （第一圈之内是 0，之后每段涨 1/区域数，指数作用在血 ×1.35、移速 ×1.06、伤害 ×1.15 上）——
  这样"每段涨多少"和区域总数无关，以后再加区域不会把曲线冲淡。
  HUD 和结算都显示「第 N 轮」，进新一轮时弹横幅。实测机器人第 1 轮 108s → 第 2 轮 87s → 第 3 轮 85s。
- **区域推进 = 一段清场 + 一场 Boss**：清场 45 秒后本区域的 Boss 堵门（HUD 的倒计时换成「Boss 战」），
  打倒它（裂变者裂出的子体也要清掉）才换区，换区时弹横幅（荒野 → 沼泽 → 巢穴 → 雪原 → 循环）。
  Boss 战期间区域时间冻结，所以下一段照样有完整的清场时间。兵种配比、地形风格、冲锋潮兵种和画面色调都跟着区域变。
  荒野开阔、杂兵冲锋兵为主；沼泽泥地遍地、射手和分裂怪变多；巢穴岩块多、肉盾和召唤者的地盘，宝箱也更勤；
  雪原空旷（地形最稀疏，没掩体也没减速带），冲锋兵和射手成群，压力来自数量。
  第一个区域是**基准区域**，不改任何权重和地形，平衡数据以它为锚点（内容校验会拦住给它加配置）。
- **交界 Boss 的战利品**：打倒挡门的 Boss 之后三选一（点击或 `1/2/3`），挑完才换区。
  和升级卡分开的两个池子：升级卡是构筑选择，一局十几次；战利品是一次性补给，一局最多三四次，
  所以给得直接——疗愈（回满血 + 上限 15）、精炼（最弱的武器 +2 级）、磨刀（伤害 +20%）、
  补给（重抽 +1、排除 +1）、贯注（攻速 +18%、移速 +8%）、学识（经验 +40%）。战利品没有重抽和排除。
  满足条件时这三张里会有一张是**觉醒卡**（二段进化，见武器那一节）。
- **找得到 Boss**：Boss 或精英跑出视野时，屏幕边缘会画一个指向它的三角（越远越淡）；
  Boss 血条旁边写着「打倒它才能进沼泽」，出场横幅也写明是谁挡了路。
  交界 Boss 是换区的唯一条件，看不见它的时候很容易误判成"卡住了"。
- **三种精英原型**（每 40 秒出场一只，每只随机抽）：
  - 自爆者：死后在原地留一颗延时炸弹（红圈预警，0.9 秒后炸），敌我都吃伤害 —— 杀完得走开
  - 护盾者：3 秒无盾 / 2.2 秒开盾循环，开盾时只吃 30% 伤害，逼你等窗口或先打别的
  - 裂变精英：死后裂成三只小精英（小的不再裂）
- **四种 Boss 原型**，由区域决定，共用同一套状态机（追人 → 预警 → 出招 → 硬直）但招式权重和机制不同：
  - 蛮兽（荒野）：偏爱冲撞，基准原型
  - 裂变者（沼泽）：血少一些，死后裂成两只小 Boss（子体不再裂），清场顺序要想清楚
  - 守卫者（巢穴）：偏爱召唤，护卫（肉盾）在场时自己减伤 55%，逼你先清护卫再打本体
    —— 减伤中会多套一圈护卫色的圈，HUD 也会写明，不然"打不动"看起来像 bug
  - 幻影（雪原）：偏爱冲撞，但**冲撞开始的那一刻会闪到你背后**再冲，所以不能只盯着
    它预警时站的位置往反方向躲。落点会炸一圈提示
- **成就与统计**：主菜单里单独一屏。左栏累计数字（总局数、累计击杀、遇到 Boss、开箱、进化次数、
  最长存活、单局最多击杀、最高轮次、已通关难度、每个角色的最好成绩），右栏 12 个成就带进度条。
  成就不存"已解锁"状态，每次都从统计现算——加成就不需要迁移存档。
- **残片与局外进度**：每局按存活时长、击杀和打通的区域段数结算残片
  （`floor(t/6) + floor(kills/12) + 段数 × 10`，中位约 54 片）。
  残片用来解锁角色（游侠 35 / 术士 50 / 猎手 65）和买**永久强化**（体质 +生命、锐度 +伤害、迅捷 +移速，各 3 级）。
  锁着的角色卡点一下是"买下来"，买完停在首屏，再点一次才开局。存档在 localStorage 里。
  永久强化幅度刻意压得很小（满级也只有 +30 血 / +12% 伤害 / +9% 移速），
  `npm run check` 有断言盯着它：满级存档不许超过新存档的 1.8 倍，且全解锁要落在 6–20 局之间（当前中位约 10 局）。
- `WASD` / 方向键移动；鼠标按住朝指针方向走；手机按住屏幕拖动出虚拟摇杆
- `Shift` / 空格 / 右键冲刺（手机双击）：0.16 秒冲出约 125px，期间 0.3 秒无敌可穿怪，冷却 3 秒
- `Q` / `E` 放**主动技能**（手机点右下角两个按钮）。技能从升级卡里学，最多带 2 个、各 3 级：
  - 震荡波：推开周围敌人并眩晕（眩晕期间它们不动也不咬人）
  - 时缓：短时间内全场敌人大幅减速
  - 磁吸：把场上所有经验球收到身上
  - 诱饵：放个假目标，敌人会改去打它
- 攻击自动，升级时三选一（点击或 `1/2/3`）。选卡界面还能：
  - **重抽**（`R` 或点按钮）：换掉这三张，每局 2 次
  - **排除**（点卡片右上角 `×` 或 `Shift+数字`）：这张卡本局不再出现，每局 1 次
- `ESC` / `P` 暂停并查看全部装备与属性，`M` 静音；首屏按 `H` 看操作说明与兵种图例
- 死亡结算会列出：每把武器的伤害占比、血是被谁打掉的、每 15 秒的击杀曲线，
  并且可以按 `R` 回看这一局的完整回放
- 武器最多同时带 3 把，共 7 把基础武器：追踪弹、光环、穿透枪、地雷、回旋镖、闪电链、光束
- **光束**是唯一的"持续单体"武器：锁定最近的敌人一直照，照得越久越烫（伤害最高 ×2.2），
  脱靶就迅速降温。其余六把都是一次性判定，缺一个能对单体持续加压的选择——
  交界 Boss 改成挡门之后，这一条直接决定某些流派能不能推进。
- **进化**：两把特定武器都到 3 级时会出现进化卡，两把合成一把并腾出一个槽位。
  基础武器大多出现在两条配方里，所以"该凑哪两把"本身就是取舍
  - 光环 + 闪电链 → 电场（球间连电弧，偏清场）
  - 地雷 + 穿透枪 → 爆破枪（穿透弹开路 + 沿途爆炸走廊）
  - 回旋镖 + 追踪弹 → 归巢弹（会拐弯追人，偏单体）
  - 穿透枪 + 闪电链 → 链式激光（激光命中后向附近连锁放电）
  - 光环 + 地雷 → 环形雷场（光球轨道外侧不断埋雷）
  - 光束 + 穿透枪 → 贯日炮（持续光柱烧穿一整条线）
  - 光束 + 光环 → 新星（以自身为中心不断脉冲爆发）
- **二段进化（觉醒）**：进化武器**满级**之后，如果已经打倒过 3 只交界 Boss，
  交界战利品里就会出现一张觉醒卡（进化色描边）。觉醒是原地换武器、占同一个槽，
  只有一个终态（不再升级），给的是机制变形而不是数值再翻倍：
  - 电场 → 磁暴场：不再靠光球接触，以自身为中心持续放电，范围翻倍
  - 归巢弹 → 蜂群：弹药不再很快消失，一群弹药常驻场上自己找人
  - 链式激光 → 雷暴：连锁不再是一条链，每个被击中的目标再向外分叉一次
  觉醒卡刻意不进升级卡池：卡池从十几项涨到 25 项那次，平均存活直接从 118s 掉到 73s。
  它同时是无尽轮次的目标——以前打到第 N 轮只有数字在涨，没有具体想拿的东西。
- **词条**：除了纯数值的狠/快/滑/肉/贪，还有改变行为的准（暴击）、吸（击杀回血）、
  学（经验加成）、炸（拾取经验球时炸一圈）
- **诅咒卡**：有代价的强化，例如「全体伤害 +50%，但敌人移速 +20%」。红框标出
- 敌人靠形状区分：杂兵（圆）、冲锋兵（三角，快而脆）、肉盾（方，慢而厚）、
  射手（五边形，拉开距离放子弹，开枪前会亮一圈）、分裂怪（圆内带环，死后裂成两只小怪）、
  召唤者（八边形，不断产冲锋兵）、精英（菱，首只 30 秒，之后每 40 秒一只）
- Boss（六边形）在每段区域的交界出场（清场 45 秒之后），打倒它才换区。行为是 追人 → 预警 0.8 秒 → 冲撞 / 旋转弹幕 / 召唤小怪，
  预警时屏幕顶部会写出它要放哪招。Boss 弹幕只打玩家，冲刺无敌可以穿过去
- Boss 预警的 0.8 秒里，地上会画出它这一招的范围：冲撞是一条通到底的带子（长度就是它能冲多远）、
  弹幕是一圈放射线、召唤是几个小圈。越接近出招越实，不用先认字再反应
- Boss 掉到半血会**狂暴**：出招更快、弹幕更密、召唤更多，血条上有半血刻度提示
- **打断**：Boss 预警的 0.8 秒里打掉它 8% 最大生命（狂暴后要求 1.6 倍），这一招就没了，
  Boss 还要硬直 1.6 秒。血条下方有打断进度条。因为自动攻击锁最近的目标，
  想打断就得主动贴上去——这是 Boss 战里最主要的操作决策
- 节奏是 30 秒一个循环：常规 22 秒 → 冲锋 4 秒（四面围一圈）→ 喘息 4 秒（停止刷怪）
- **地图元素**（围着玩家动态生成）：
  - 岩块：挡玩家、挡敌人、吃掉子弹——包括 Boss 和射手的弹幕，可以当掩体
  - 泥地：玩家和敌人都减速 45%，可以拿来卡怪；冲刺不吃减速
  - 宝箱：走上去就开，白送一次升级。同时只有一个，冷却 32 秒（巢穴 20 秒，那儿宝箱更勤）
- 一局中位约 92 秒，通常能打到 1–2 只交界 Boss

## 武器沙盒

调武器的工具屏：主菜单最后一项，或直接 `?sandbox=1`。

- 面板贴在屏幕**底部**，`Tab` 或点右上角的把手可以折叠（折叠后只剩一条把手，整屏都是战场）。
  这样左上角的血条/经验条和技能槽都不会被挡住。
- 武器区 3 列 × 6 行，列出全部 17 把（基础 / 进化 / 觉醒，描边颜色区分）：每行右侧有 `[-]` `[+]` 两个按钮，
  点着调等级；减到 0 就卸掉。点行的空白处等价于 `+1`，`Shift` 点和右键仍然是 `-1`（快捷方式，不是唯一方式）。
- 右侧是开关和靶子：无敌、冻结刷怪、锁 3 个槽位（可放开，试任意组合）、时间 ×0.5/×1/×2、
  放一只杂兵 / 围一圈 20 只 / 放精英 / 放 Boss / 清空敌人 / 清空武器。数字键 `1`-`4` 放靶子、`0` 清空、`ESC` 退出。
- 面板标题行显示最近 3 秒的实时输出，用来和 `npm run balance` 的台架 DPS 对照。
- 沙盒是工具，所以**不写存档、不记成就、不结算残片、不录像**，升级卡也直接丢掉（等级手动调）。
  「围一圈 20 只」对应的正是平衡台架里的群体场景，这样台架数字和眼睛看到的画面能对上。

## 崩了怎么查

主循环有一层 try/catch（不加的话异常会断掉 rAF 链条，画面定格但玩家看不到任何提示）。
崩溃时除了控制台堆栈，还会把**复现材料**写进 `localStorage` 的 `survivor.crash`：

```js
// 浏览器控制台里导出
copy(localStorage.getItem('survivor.crash'))   // 或者 JSON.parse(...) 自己看
```

里面有 `message` / `stack`，以及这一局的**完整录像**（seed + 角色 + 强化 + 难度 + 每帧输入）。
把 `report.replay` 存成 `crash.json` 之后：

```bash
npm run replay -- crash.json    # 精确重演崩溃那一局
```

这是"世界完全确定性"额外换来的好处：崩溃不再是一段没有上下文的堆栈。
读档继续的局和沙盒局不录像，那时存的是世界快照（`snapshot`）。
