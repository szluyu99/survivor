# 色块幸存者

浏览器里直接开打的割草小游戏。自动攻击，你只管走位，边跑边升级，看能活多久。一局一两分钟。

**零依赖、零构建**：三个 HTML/JS 文件加一个静态服务器就能跑，没有 npm 依赖、没有打包步骤。

## 本地跑

```bash
npm run serve      # 等价于 python3 -m http.server 8080
# 打开 http://127.0.0.1:8080
```

不能直接双击 `index.html`——用了 ES module，`file://` 协议下会被 CORS 拦掉，必须经 HTTP 服务。

## 开发命令

```bash
npm test           # 逻辑层测试 + 渲染层烟测（41 个）
npm run balance    # 平衡回归报告：武器强度、局长、兵种出场、帧率敏感度、单帧耗时
node tools/make-og.mjs   # 重新生成分享卡片图 og.png
```

## 代码结构

- `src/sim.js` —— 纯逻辑，不碰 DOM。刷怪、碰撞、经验、升级、波次。所有实体走对象池，热循环零分配（避免 GC 抖动）。可以在 node 里直接跑，测试和平衡脚本都依赖这一点。
- `src/weapons.js` —— 武器定义。每把武器 = 一条配置（名字、5 级数值表、升级文案、面板 info）+ 一个 `tick`。加武器只需往 `WEAPONS` 里加一项，不用改 sim。
- `src/game.js` —— 渲染、输入、主循环、粒子/震屏/跳字。逻辑层通过 `fx` 事件池告知"发生了什么"，这里消费成画面和声音。
- `src/palette.js` —— 语义化色板。所有颜色都在这里，其他文件零硬编码色值。
- `src/audio.js` —— 音效全部 Web Audio 现场合成，不加载音频文件。

## 玩法

- `WASD` / 方向键移动；鼠标按住朝指针方向走；手机按住屏幕拖动出虚拟摇杆
- `Shift` / 空格 / 右键冲刺（手机双击）：0.16 秒冲出约 125px，期间 0.3 秒无敌可穿怪，冷却 3 秒
- 攻击自动，升级时三选一（点击或 `1/2/3`）
- `ESC` / `P` 暂停并查看全部装备与属性，`M` 静音
- 武器最多同时带 3 把，共 6 把可选：追踪弹、光环、穿透枪、地雷、回旋镖、闪电链
- 敌人：杂兵（圆）、冲锋兵（三角，快而脆）、肉盾（方，慢而厚）、精英（菱，30 秒一只）
- Boss（六边形）45 秒一只、之后每 55 秒。行为是 追人 → 预警 0.8 秒 → 冲撞 / 旋转弹幕 / 召唤小怪，
  预警时屏幕顶部会写出它要放哪招。Boss 弹幕只打玩家，冲刺无敌可以穿过去
- 节奏是 30 秒一个循环：常规 22 秒 → 冲锋 4 秒（四面围一圈）→ 喘息 4 秒（停止刷怪）
- 一局大约 80–110 秒，通常能碰到 1–2 只 Boss

## 部署

推到 GitHub 后开启 Pages，`.github/workflows/deploy.yml` 会在测试通过后自动部署仓库根目录。`index.html` 里的 `og:image` 用的是相对路径，Facebook 需要绝对地址，域名定了之后换成完整 URL。
